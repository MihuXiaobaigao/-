# 便读技术架构

## 1. 总体结构

```text
平板 UI
   |
应用服务层（阅读、批注、AI、知识库）
   |
领域核心（本仓库 src/core）
   |
本地适配器
   ├─ 文档存储：PDF、图片、画板资源
   ├─ 元数据存储：关系、进度、词典、清理任务
   ├─ 全文索引：FTS
   ├─ 向量索引：语义检索
   └─ 安全存储：每位用户自己的 API Key

外部网络
   └─ 用户配置的多模型档案：解释、翻译、抽取、生成、问答，以及当前扫描页/画板视觉 OCR
```

领域核心不依赖 React、Vue、PWA 或 Android。后续页面原型只替换 UI 层，不改变数据规则。

## 2. 本地优先与用户隔离

每位用户拥有独立的本地数据库、文件目录、API Key 和知识索引。隔离通过“一个用户一个数据库”完成，而不是在同一数据库里增加 `user_id` 后依赖查询条件。

这样即使未来发生代码缺陷，也不会因为漏写一个查询条件而读到另一位用户的数据。

两台设备不建立同步协议，不共享备份口令，不互相发现。

## 3. 推荐交付形态

- 小米 Pad：共享网页业务代码，使用 Capacitor 封装为 APK。
- iPad：共享同一网页业务代码，作为 PWA 安装到主屏幕。
- 两边采用统一的本地仓储接口。
- Android 包装层提供文件、SQLite、安全存储和原生分享能力。
- iPad PWA 使用 IndexedDB/OPFS 等浏览器持久化能力，并要求用户定期导出加密备份。

## 4. 内容处理流水线

```text
导入 PDF
  -> 校验文件哈希与重复文件
  -> 提取文字 / 无文字层时由用户触发当前页视觉 OCR
  -> 结构切分（章节、段落、句子）
  -> 建立短原文证据
  -> 提取概念、主张、人物、术语
  -> 合并重复节点
  -> 建立带依据的知识关系
  -> 生成本地全文与向量索引
  -> 验证来源定位和证据完整性
  -> 进入 7 天保留期
  -> 清理原始 PDF
```

AI 对话采用同样的生命周期：

```text
选段问答 / 知识库问答
  -> 提取可长期保留的知识
  -> 生成对话摘要
  -> 关联证据与知识节点
  -> 验证摘要不为空
  -> 进入 7 天保留期
  -> 清理原始消息
```

## 5. 知识库检索

知识库回答不能只使用关键词，也不能只使用向量。建议采用混合检索：

1. 全文关键词检索获取精确命名和术语。
2. 向量检索获取语义相近但措辞不同的证据。
3. 图谱检索获取相邻概念、来源与反例。
4. 对合并后的候选证据去重并重新排序。
5. 只把预算范围内的必要证据发送给当前任务绑定的模型。
6. 对模型引用执行本地校验，拒绝引用不存在的证据编号。

嵌入使用独立可配置的 OpenAI 兼容接口；默认首选硅基流动免费 `BAAI/bge-m3`，限流或故障时自动切换 `Pro/BAAI/bge-m3`。嵌入只用于检索，不替代最终回答模型。

## 6. 知识关系

节点类型包括：

- 概念
- 主张
- 人物
- 书籍
- 论文
- 原文段落
- 用户笔记
- 画板
- AI 对话摘要
- 英语单词

关系类型至少包括：

- 支持
- 反驳
- 因果
- 属于
- 相似
- 对比
- 来源于
- 定义于
- 举例说明
- 与用户经历相关

每条关系保留生成模型、生成时间、依据证据和置信度。AI 自动更新不能覆盖仍被其他证据引用的历史关系。

### LLM Wiki 式持续整理

知识图谱不只保存一次抽取结果，而是维护持续生长的 Wiki 层：

1. 所有永久证据进入同一整理队列，包括 PDF 原文、视觉证据、文字笔记、画板识别、词典语境、知识库对话摘要和用户主动上传的附件。
2. 第一阶段分析跨来源主题、已有页面复用点、冲突与知识缺口；第二阶段只依据证据生成或更新页面正文、摘要、别名和关系。
3. 稳定标题和别名优先复用已有页面，避免同一概念因英文原名或简称不同而分裂。
4. 每个 Wiki 页面、关系和正文中的事实继续绑定证据编号；无证据页面与悬空关系不能写入。
5. 问答先进行关键词与语义检索，再沿 Wiki 关系图做一跳、两跳补证，将邻居页面的原始证据加入候选集后重新排序。

## 7. 数据安全

- API Key 不进入源码、日志、备份元数据或 AI 请求正文。
- Android 使用系统安全存储。
- PWA 使用 Web Crypto 加密后保存在本机。
- 用户笔记、原文证据和画板默认不经过任何第三方服务。
- 发送 AI 前显示本次将发送的内容类型。
- 加密备份不包含 API Key。

4. 可配置模型能力测试与任务提示词。
5. 混合检索与引用校验。
6. 接入页面原型。
7. 小米 APK 打包。
8. iPad PWA 安装、持久存储和备份验证。
