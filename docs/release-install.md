# 便读 1.0.18 安装与数据说明

## 小米 Pad 7S Pro

1. 将 `便读-1.0.18-小米.apk` 传到平板。
2. 在系统文件管理器中打开 APK，允许当前文件管理器“安装未知应用”，然后安装。
3. 首次打开后，在“设置 → 我的模型”填写这台平板自己的接口地址、模型 ID 和 API Key；可添加官方预设或任意兼容模型，并在“功能分配”中为每项 AI 功能选择已保存密钥的模型。
4. 后续升级必须继续使用本项目的正式签名，才能覆盖安装并保留本机数据。不要先卸载旧版；覆盖安装会保留 IndexedDB 中的书籍、笔记、画板、词典和知识库。
5. 阅读时如果系统询问“允许修改勿扰模式/通知策略”，开启一次即可。便读会读取实际授权状态，已授权后不会在你每次进入阅读时重复跳转。

APK 包名为 `cn.biandu.reader`，最低支持 Android 7（API 24），目标版本为 Android 16（API 36）。包含原生文件选择器备份入口，不申请通讯录、定位、相机或存储目录总权限。

## iPad A11 PWA

iPad 的 PWA 必须从可信 HTTPS 地址打开，不能直接双击本地 HTML，也不能用普通局域网 `http://` 地址安装。把 `便读-1.0.18-iPad-PWA.zip` 解压，并把解压后的全部文件作为站点根目录部署到固定域名（GitHub Pages、Cloudflare Pages、自有 HTTPS 静态服务器均可），然后在 Safari 中：

1. 打开该 HTTPS 地址并等待首页完成加载。
2. 点 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕启动“便读”，再填写这台 iPad 自己的模型档案和 API Key。

同一台 iPad 必须始终使用同一个 HTTPS 域名和路径，否则 Safari 会把它视为另一套本地数据。应用不会在两台平板之间同步任何内容。

## 数据与备份

- PDF、笔记、图片、画板、词典、永久证据和知识图谱只保存在当前平板。
- API Key 使用 AES-GCM 加密保存在本机，不写入源码，不进入备份。
- 模型 ID、接口地址和功能绑定均可随时在设置中修改，不需要更新 APK 或 PWA。
- 中文语义检索默认使用硅基流动免费 `BAAI/bge-m3`；免费模型限流或故障时自动使用 `Pro/BAAI/bge-m3` 备用档案。两个档案都可替换。
- “设置 → 导出完整备份”会保存全部用户资料，但不包含 API Key。
- 恢复备份时会按记录 ID 合并到当前平板：缺失内容会补齐，本机较新的笔记、画板和知识节点不会被旧备份覆盖；建议恢复前仍先导出一份当前备份。
- 小米 APK 会打开系统文件选择器选择备份保存位置；iPad PWA 使用 Safari 下载。
- 小米 APK 已关闭 Android 系统云备份、设备迁移备份和应用数据提取；两台平板不会通过系统账号或换机流程同步。跨设备保存只能由用户主动导出备份文件。
- 设置页会显示系统是否授予持久存储、当前用量、可用配额和最近一次完整备份时间。持久存储也不等于永久保险，应用数据被手动清除、卸载或设备损坏时，只能从外部备份恢复。
- 阅读位置会立即写入本机恢复日志，快速退出后重新打开仍回到最后阅读页；翻译更新、原文清理和笔记保存使用原子写入或回滚保护，异常中断不会留下半完成数据。
- iPad PWA 首次安装会缓存阅读器所需的字符映射和字体；安装完成后即使断网，也可继续打开本地 PDF、笔记、画板和词典。AI 问答仍需联网。

## 当前边界

- 有文字层的 PDF 可以直接阅读、选段、翻译和建立知识证据。
- 文字模式会重新排版；点击“原页视图”可查看并永久保存 PDF 的照片、图表、公式和原始版式。
- 在“原页视图”中点击“框选图片/公式”，即可用焦点笔 Pro、手指或鼠标拖出选区。裁切图会永久保存在本机，只把该选区和问题发送给单独配置的多模态模型。
- 页面快照和视觉证据完成前，应用不会清理原始 PDF；清理后仍可从本机快照打开原页。
- 扫描页没有文字层时会显示原始页面；点击“AI 识别扫描页”后才会把当前页图像发送给所配置的 OCR 模型，生成文字层并提供人工校对入口。
- 画板可点击“AI 识别手写”，只发送当前这一张画板图像；原始笔迹、图片、文字和便签始终永久保留。
- 小米焦点笔 Pro 已按 `pointerType=pen`、压感、倾斜、扭转、硬件橡皮与掌托拒绝实现；实体笔的按键和压感曲线仍需在设备上最终验收。
- OCR 和手写识别可能出错；复杂公式、极潦草字迹和低清晰度图像不能保证完全准确。OCR 校对或重新识别后会撤销旧知识校验，重新整理通过前不会清理原文。
- 真实 AI 质量取决于用户填写的接口、模型和 Key。应用内置连接测试，不会把失败显示成成功。
- “图片与公式讲解”和“扫描页识别”必须选择支持图片输入的模型；文本模型不能代替视觉模型。
