# 便读功能详情

- 导入真实 PDF，提取文字并建立本地原文证据。图表、表格和独立公式会建立版面保护区，避免图片内散字混入正文。
- 在“原页视图”中按 PDF 原貌查看照片、图表、公式和复杂版式，并用触控笔、手指或鼠标框选任意区域。
- 图片/公式框选会永久保存裁切图，并只把该区域、问题与会话历史发送给独立配置的多模态模型；回答可转为图片笔记或永久知识证据。
- 视觉页面会生成永久 JPEG 快照和可引用视觉证据；七天清理必须等全部页面快照与图片、图表、公式证据完成后才允许执行。
- 字体、字号、颜色、背景、行距、段距、页边距和翻译粒度调节。
- 单栏连续阅读会按“页面 + 段落 + 段内偏移”恢复位置；改字号、行距、版面宽度、窗口方向或异步加载图片后不会退回页首。阅读列支持 760–1120px 宽度调节，并持久保存字体与排版偏好。
- 文字阅读工具栏收敛为六个动作：阅读设置、翻译选中内容、加入词典、切换 PDF 原页、句子笔记和全文翻译；目录、全局 AI 大纲等次要入口不再占用阅读工具栏。
- 进入小米版阅读后立即隐藏应用导航并进入 Android 沉浸模式，竖屏同样铺满屏幕；首次使用需在系统设置中授权勿扰模式，之后进入阅读会静音其他应用通知，离开阅读或切到后台时自动恢复原勿扰设置。
- 单词翻译会先立即保存到本机词典，再请求音标、词性、释义与原句翻译；网络或模型失败不会丢失已选单词。全文翻译采用“逐页保存 → 再次点击暂停并只显示原文 → 第三次从未完成页继续”的连续流程。
- 文字阅读取消浏览器平衡换行，保留自然行流；阅读中创建文字笔记或画板均使用原位浮层，不离开当前页。画板编辑采用全画布布局和右侧图标工具轨道。
- 上次阅读位置会自动作为唯一的“继续阅读”位置，同时保留阅读进度和阅读时间统计。
- 文字笔记、图片笔记、选段笔记和永久标注。
- 每次批注创建独立无限画板；画板编辑采用与自由笔记参考图一致的全屏画布、顶部胶囊工具栏和右侧纵向工具轨道，荧光笔颜色以笔杆形式直接嵌在轨道中。
- “画板”入口先显示“我的画板”列表，点“添加画板”才进入全屏编辑器。画板卡片可导出 `.biandu-board.json` 完整文件，导入会恢复全部笔迹、文字、便签、图片、纸张和视口。
- 画板支持导出自动裁边的单页 PDF，以及 PNG 图片；PDF 保留白色纸张、图片、文字和手写内容，适合打印与分享。
- 小米焦点笔 Pro 使用原始高频笔点与合并采样，保存压力、倾斜、扭转和时间戳，压感实时改变线宽，铅笔随倾斜形成笔锋；手掌先落或笔尖书写时都会隔离掌触，双指缩放不被阻断。
- PDF 文字重建会合并同一栏内无句末标点、但被 PDF 视觉间距拆开的连续源行；排版版本升级后，已有书籍会从本地 PDF 自动重建阅读块。
- 排版升级不再覆盖 AI 校对完成的页面文本；校正文本缺字时会优先保留原内容并只重排段落。旧版迁移可能覆盖过的页面会显示“重新校对文字”，使用本机 PDF 修复。
- 笔身按键单击切换橡皮，按住后书写会临时擦除并在抬笔后恢复原画笔；翻转到硬件橡皮端可直接擦除。PDF 原页、全画板与阅读内浮层画板全部使用同一套压感和掌托逻辑。
- 画板对齐成熟手写笔记的核心交互：钢笔、铅笔、荧光笔、选择移动、套索多选、矩形、椭圆、空白/方格/点阵/深色纸张，以及复制、删除与快捷键操作。
- 扫描页可由用户配置的多模态模型生成带标题、正文、图注和公式类型的文字块，并提供逐页人工校对；画板可识别手写、箭头结构和关键词。识别只发送当前页或当前画板图像。
- 双语翻译严格一句英文、一句中文上下排列；超长复合句按自然语义边界拆分，已翻译页和未翻译页在连续阅读流中同时展示。
- 阅读工具栏六个动作使用纯图标，不显示长文字；长按任一按钮会显示名称和具体用途，未到可用条件时仍可长按查看原因。
- 整书翻译按页事务保存并逐页立即计入已保存页数；取消后保留全部已完成页，下次从未完成页继续。全书完成后同一按钮在“只显示原文”和“显示译文”之间切换，恢复译文不再调用模型。
- 点击英文单词后可直接“翻译选中”或“加入词典”，两者都会生成完整音标、词性、释义和语境并自动去重；选句翻译只显示中英对照，不写入词典。
- PDF 原页模式只保留原貌阅读、钢笔、荧光笔、橡皮、撤销、翻页和缩放，不混入文字翻译、词典或 AI 查询。
- 永久证据、知识节点、带依据的 AI 关系、知识图谱和引用校验。
- 知识图谱采用 LLM Wiki 式持久化整理：AI 分两阶段跨来源分析并生成或更新 Wiki 页面，复用稳定标题与别名，区分原文、笔记、画板、PDF 附件和 AI 对话摘要；所有页面关系仍逐条绑定永久证据。
- 知识图谱问答会从关键词与语义检索的种子节点沿 Wiki 链接做一跳、两跳补证；图谱支持搜索页面、别名和摘要，并在节点详情中直接查看 Wiki 正文、关系理由和来源证据。
- 统一使用 `grounded-v3` 结构化提示词：AI 原文与指令隔离、每条事实结论独立绑定证据、引用逐字校验；视觉内容使用页面快照和框选区域作为独立证据，模型输出不合格时自动纠正一次，网络限流和临时服务错误自动重试。
- 知识库会显示检索相关度、逐条结论来源类型和可定位引用；低相关结果明确警告，不伪装成确定答案。
- PDF 原文与 AI 原始对话只有在知识整理验证完成且满 7 天后才允许清理。
- API Key 使用 AES-GCM 加密保存在本机；不进入源码和备份。
- 设置中可新增、编辑、测试和删除任意 OpenAI 兼容模型档案，并提供阿里云百炼、DeepSeek、智谱、月之暗面、百度千帆和 OpenAI 的官方模型预设；选段、图片与公式讲解、知识库、知识整理、翻译、词典、OCR 与手写识别可分别绑定不同模型。Qwen-MT 翻译档案请求时会自动附带翻译参数。
- 支持为问答、选段、多模态视觉、知识库、知识整理、翻译、词典、OCR 和手写识别分别绑定不同模型；模型接口地址、模型 ID、密钥、连接测试和功能分配均在设置页管理。
- 首次安装自带 DeepSeek Flash 问答模型、SiliconFlow 免费 BGE-M3 向量模型和 Qwen-MT Flash 翻译档案。密钥在首次启动后以 AES-GCM 加密存入本机，用户可继续编辑或替换；生成参数按任务自动选择，不向用户暴露温度设置。
- 知识库采用单一对话入口，支持“对话 / 任务”模式。任务模式可把已校验的知识回答整理为 PDF 报告、Word 文档或 PPT 演示，三种文件均在本机生成；知识库页面本身不提供模型选择。
- 知识库输入框的“＋”只负责导入图片、PDF、Markdown 与纯文本附件。附件会保存为永久证据并自动并入 Wiki，不再和“任务格式”复用；任务格式只在“任务”模式内选择。
- 知识库回复保持普通 AI 对话形态，不展示徽章、检索面板和长串证据卡片。任务模式只在用户明确要求生成、导出或做成指定文件时创建下载，普通提问始终只回答。
- 知识库 Agent 接入应用内置 MCP：`knowledge.answer` 负责检索、回答与引用校验，`artifact.create` 负责按用户明确指定的格式生成文件。两者通过 MCP `initialize`、`tools/list`、`tools/call` 协议调度。
- 知识库支持持久化多轮对话、新建对话和可收起的对话栏；同一对话可持续追问，历史对话点击即可切换。
- 提示词按 LangGPT 结构化方式组织，并根据 DeepSeek、千问、OpenAI 兼容接口和本地模型分别追加适配约束。
- 小米版的所有模型请求优先通过 Android 原生网络层发送，避免 WebView 跨域限制导致“测试连接通过、正式功能却报 CORS”；网页版才使用浏览器请求。
- 中文知识库使用 BGE-M3 语义向量与本地关键词混合检索。默认首选硅基流动免费 `BAAI/bge-m3`，限流或故障时自动切换 `Pro/BAAI/bge-m3`；两个向量档案也可替换成任意兼容服务。
- 完整本地备份与恢复，小米 APK 使用系统文件选择器保存。
- 长期数据安全：阅读位置同步写入本机恢复日志，快速退出后仍能回到刚翻到的页面；画板先保存笔迹再补建知识关联；翻译替换和七天原文清理使用原子事务；恢复旧备份只合并缺失记录，不会覆盖较新的本机内容。
- 设置页显示持久存储是否获准、当前用量与可用配额，并记录最近一次完整备份。PWA 缓存使用构建内容哈希自动更新；Android 关闭系统云备份和设备迁移备份，两台平板保持完全独立。
- iPad 主屏幕 PNG 图标、横竖屏布局、安全区和离线 PWA 壳。
- iPad PWA 首次安装会预缓存 PDF.js 字符映射与标准字体，本地 PDF 的离线阅读不依赖先在线打开过同类文档。
